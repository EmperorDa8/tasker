# Bundled icon set

`icons.js` is generated by `scripts/build_icon_pack.py` from **Material Symbols**
(Rounded, weight 400), published by Google under the **Apache License 2.0**.

https://fonts.google.com/icons

## Why the paths are bundled rather than linked

The extension's content security policy allows no remote script, style, font or
image, and the Web Store treats an undeclared network request as a policy issue.
A CDN icon font - Font Awesome or the Material Symbols webfont - therefore cannot
be used here at all. Bundling the path data also means icons paint on the first
frame, offline, with no icon-font flash.

## Adding an icon

1. Add its Material Symbols name to `ICONS` in `scripts/build_icon_pack.py`.
2. Run `python scripts/build_icon_pack.py`.
3. Use it as `<span data-icon="the_name" data-size="sm"></span>`.

The build reports any name Google does not serve rather than emitting a blank
glyph, so a typo fails at build time instead of showing up as a hole in the UI.
